# Advanced Portfolio Website

## 📌 Project Overview

This is a modern responsive portfolio website created using advanced CSS concepts. The project demonstrates CSS Grid, Flexbox, CSS Variables, Animations, Transitions, and responsive web design.

## 🚀 Features

- Responsive Design
- CSS Grid Layout
- Flexbox Layout
- CSS Variables
- Dark/Light Theme Toggle
- Smooth Animations
- Scroll to Top Button
- Interactive Project Cards
- Contact Form
- Mobile Friendly Design

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
